Derived Types#

This library implements the data structures described by the NetCDF data model.

DIMENSION_TYPE – NetCDF Dimension#

Component

IDinteger(c_int)
NetCDF dimension identifier.

NAMEcharacter(len=:), allocatable
Dimension name.

LENinteger(int64)
Dimension length.

IS_UNLIMlogical
Whether the dimension is unlimited.

ATTRIBUTE_TYPE – NetCDF Attribute#

Component

IDinteger(c_int)
NetCDF attribute identifier.

NAMEcharacter(len=:), allocatable
Attribute name.

DTYPEinteger(data_type)
NetCDF external data type.

LENinteger(int64)
Number of stored values.

BUFFERinteger(int8), allocatable
Owned byte storage for copied values.

PTRinteger(int8), contiguous, pointer
Borrowed byte storage for contiguous caller-owned values.

VARIABLE_TYPE – NetCDF Variable#

Component

IDinteger(c_int)
NetCDF variable identifier.

NAMEcharacter(len=:), allocatable
Variable name.

DTYPEinteger(data_type)
NetCDF external data type.

LENinteger(int64)
Total number of stored values.

DIMStype(dimension_type), allocatable
Dimensions in Fortran order.

ATTStype(attribute_type), allocatable
Attributes attached to the variable.

BUFFERinteger(int8), allocatable
Owned byte storage for copied values.

PTRinteger(int8), contiguous, pointer
Borrowed byte storage for contiguous caller-owned values.

GROUP_TYPE – NetCDF Group#

Component

IDinteger(c_int)
NetCDF group identifier.

NAMEcharacter(len=:), allocatable
Group name.

DIMStype(dimension_type), allocatable
Dimensions defined by the group.

ATTStype(attribute_type), allocatable
Attributes attached to the group.

VARStype(variable_type), allocatable
Variables defined by the group.

GRPStype(group_type), pointer
Child groups, shared through pointer association.

NETCDF_TYPE – NetCDF Root Group#

Extends

GROUP_TYPE

Component

FILEcharacter(len=:), allocatable
Path of the open NetCDF file.

MODEinteger(c_int)
NetCDF file access mode.

ERROR_TYPE – Operation Error Result#

Component

CODEinteger(c_int)
NetCDF status code; zero indicates success.

MSGcharacter(len=:), allocatable
Diagnostic message for a failed operation.

Supported NetCDF Types#

The currently supported and unsupported NetCDF types are:

  • ☑ Supported: CHAR, BYTE, SHORT, INT, INT64, FLOAT, DOUBLE

  • ☒ Unsupported: UNSIGNED BYTE, UNSIGNED SHORT, UNSIGNED INT, UNSIGNED INT64, STRING
